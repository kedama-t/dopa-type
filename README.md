# DOPA TYPE

派手な演出つきの日本語ローマ字タイピング練習。`index.html` 1枚で動作します。

- タイムアタック（60秒 / 180秒）
- スプリント（10問 / 20問 / 30問のクリアタイム）
- エンドレス（全体・直近3分・直近1分の速度とミスを常時表示）

ローマ字を打ち切ったら Enter で次のお題へ。IME は半角英数にしてプレイしてください。

## 公開URL

https://kedama-t.github.io/dopa-type/

## お題の追加

`index.html` の `QUESTION_DATA` に「表示|よみ（ひらがな）」の形式で1行ずつ追加します。`#` で始まる行はジャンル見出しです。
