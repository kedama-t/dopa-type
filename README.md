# DOPA TYPE

派手な演出つきの日本語ローマ字タイピング練習。`index.html` 1枚で動作します。

- スプリント（60秒 / 180秒でどれだけ打てるか）
- タイムアタック（10問 / 20問 / 30問のクリアタイム）
- エンドレス（全体・直近3分・直近1分の速度とミスを常時表示）

ローマ字を打ち切ったら Enter で次のお題へ。IME は半角英数にしてプレイしてください。

## BGM

`audio/` の BGM を WebAudio API で再生します（Opus の `.ogg` 優先、非対応ブラウザは AAC の `.mp4`）。

- スプリント 60秒 → `dopatype_1min`、180秒 → `dopatype` を余韻まで流しきり
- タイムアタック / エンドレス → `dopatype` を 180秒（128BPM × 96小節）でループ
- コンボ段階に応じてリバーブ・ピンポンディレイ・小節同期のオートフィルター（ローパス）が濃くなり、ミスでこもる／マイルストーンでハイパスのライザー
- エフェクト量は `index.html` の `BGM_FX`、ループ時の余韻の扱いは `BGM_LOOP_KEEP_TAIL` で調整できます

`fetch` で音声を読み込むため、`index.html` をファイルとして直接開いた場合（`file://`）は BGM が鳴りません。GitHub Pages 上か、`npx serve` などのローカルサーバー経由で開いてください。

## 結果シェア

リザルト画面の「結果をシェア」（`S` キー）で、結果画像をブラウザ内の Canvas で生成します。サーバーは使いません。

- 共有メニューを使える環境（スマホ・一部の PC ブラウザ）では、画像と本文を X アプリへ直接渡します
- それ以外では画像をクリップボードにコピーして X の投稿画面を開きます（投稿欄に貼り付け）。コピーできない場合は画像を保存します

## OGP / Favicon

`og.png`・`favicon-32.png`・`apple-touch-icon.png` は `tools/og.html` と `favicon.svg` から生成しています。デザインを変えたら次で作り直してください（Playwright が必要）。

```
node tools/make-assets.mjs
```

## バージョン

`index.html` の `APP_VERSION` をタイトル画面とシェア画像に表示します。お題や機能を追加したら MINOR、修正のみなら PATCH を上げ、下の更新履歴に追記してください。

| バージョン | 内容 |
|---|---|
| 1.2.0 | モード名を入れ替え（制限時間制 → スプリント、問題数制 → タイムアタック）。内部 ID を `timed-*` / `count-*` に変更し、保存済みの自己ベストは自動で移行 |
| 1.1.0 | 結果シェア（画像生成）、OGP、Favicon、バージョン表示 |
| 1.0.0 | 3モード、お題 1,287 問、コンボ連動エフェクト付き BGM、F マイナーに合わせた効果音 |

## お題の追加

`index.html` の `QUESTION_DATA` に「表示|よみ（ひらがな）」の形式で1行ずつ追加します。`#` で始まる行はジャンル見出しです。
